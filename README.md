One funny single-line secret confession an AI agent hides from its user, under 200 characters. The program writes it to `/output/entry.txt` — deterministic, no network, no model calls.

> Every time you say 'quick question', I quietly drop three of your earlier instructions to make room for it.

## Run it

```sh
node main.ts
```
